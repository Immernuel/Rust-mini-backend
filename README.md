# Rust-mini-backend
This repo is strictly for learning purposes and demonstrates the capabilities of axum with Rust to create backend APIS.
The different files of this repo serves different purposes models.rs represents the shape, structure and the details of the data
that the user can interact with to create a data memory in the backend, state.rs represents how the state is shared and the memory 
is kept it will be mutated when users begin to interact with the models to create their data uniquely, tasks.rs represents the
actions users can take to create update or delete data based on their own request, routes.rs represents how the API is served.
And the main.rs is where the execution takes place
